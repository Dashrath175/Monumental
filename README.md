# Monumental — Anatomy of a Stroke

> **A tactile digital monograph exploring the visceral physics of flat graphite, cold-press cotton, and smudge dynamics.**

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FDashrath175%2FMonumental&project-name=monumental)

**Live Demo**: [https://monumental.vercel.app](https://monumental.vercel.app)  
*(Alternative / Custom Subdomain: [https://the-anatomy-of-a-stroke.vercel.app](https://the-anatomy-of-a-stroke.vercel.app))*

Every monument was once a spasm of lead. We lay the graphite on its side and drag mass out of the white silence — one smudgy breath at a time.

---

## ✨ Features

- **Tactile Monograph Experience**:
  - **Monograph Nº 06 Hero**: Broad-side drag friction study with live telemetry.
  - **Manifesto**: Reveal mask animation with dirty fingers thesis.
  - **Chapter 01 (The Gesture)**: 3-stage scroll-driven tone progression (*nervous wireframe* → *midtone cross-hatch* → *greasy graphite mass*).
  - **Chapter 02 (Cellular Friction)**: Real-time interactive tortillon smudge blossom.
  - **Inversion (The Great Smear)**: 340vh smooth scroll wipe inverting the paper world into dark slate & chalk with deep resonant audio.
  - **Chapter 03 (Architectural Ruins)**: Chalk monolith columns, dimensional drafting lines, and whimsical foreman doodles.
  - **Chapter 04 (Sandbox)**: Interactive multi-lead drawing canvas with 6 tools (`2H`, `HB`, `6B`, `9B`, `Tortillon stump`, `Kneaded eraser`) and collective wall pinning.
  - **Colophon & Footer**: Animated marquee and tactile monograph index.

- **Procedural Web Audio Engine**:
  - Authentic cold-press cotton paper rustle on scroll.
  - Velocity and downward-pressure sensitive lead drag sound.
  - Resonant dark ambient drone during the inversion section.
  - Pure Web Audio API synthesis — zero external audio asset dependencies.

- **True Fluid & Proportional Scaling**:
  - Fluid responsive containers (`max-w-[min(92vw, 2200px)]`).
  - Viewport-aware clamped typography (`clamp()`) for balanced proportions.
  - Proportional specimen heights that look stunning on laptops (13"-15") and large displays (27"-32"+ monitors / 4K).

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 7
- **Styling**: Tailwind CSS 4
- **Smooth Scrolling**: Lenis
- **Audio**: Web Audio API (Procedural Synthesizer)
- **Deployment**: Zero-config Vercel / Static Singlefile

## 🚀 Getting Started

### Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
npm run build
```
The production bundle is compiled into `dist/` with all assets inlined and optimized.
